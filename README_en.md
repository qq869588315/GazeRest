# GazeRest

GazeRest is a lightweight, offline, low-distraction desktop helper for the 20-20-20 eye rest habit. It stays in the system tray, detects continuous screen time, reminds you to look into the distance, and guides a 20-second break countdown.

中文 README: [README.md](README.md)

## Features

- 20-20-20 reminders: the default reminder interval is 20 minutes. Production interval options are 20 / 30 / 40 / 50 / 60 minutes.
- Four reminder levels:
  - Level 0: status-only reminder through the main panel and tray.
  - Level 1: bottom-right lightweight reminder that does not steal focus.
  - Level 2: centered reminder card with skip, snooze, and start-break actions.
  - Level 3: immersive full-screen reminder with centered content.
- 20-second break countdown: each break starts as a fresh session with a full countdown.
- Screen-time statistics: continuous screen time, today's total screen time, and today's longest continuous streak.
- Viewing-distance calculator based on monitor width and height.
- System tray mode with adaptive visual states for running, paused, snoozed, reminder pending, break, and outside schedule.
- Bilingual UI: Simplified Chinese and English.
- Local persistence with SQLite.

## Privacy

GazeRest runs fully offline. It does not upload data, record screen content, record keystrokes, or request camera or microphone permissions. Settings, reminder events, and break sessions are stored only on the local device.

## Tech Stack

- Shell: Tauri 2
- Backend: Rust
- Frontend: React 19 + TypeScript + Vite
- Styling: CSS Modules
- i18n: i18next + react-i18next
- Local database: SQLite + rusqlite
- Desktop integrations: tray, single-instance, autostart, positioner, logging

## Architecture

GazeRest keeps UI rendering in React and moves reminder scheduling, break lifecycle, and runtime reconciliation into Rust.

- `src/ui`: main panel, settings, distance calculator, reminder overlays, break overlays, and styles.
- `src/modules`: frontend bridge, formatting, sound preview, and window helpers.
- `src/i18n`: Simplified Chinese and English copy.
- `src/types`: shared TypeScript types.
- `src-tauri/src/runtime_service.rs`: core state machine for reminders, breaks, pause, snooze, skip, and startup recovery.
- `src-tauri/src/windows.rs`: deterministic window creation, positioning, and teardown.
- `src-tauri/src/tray_service.rs`: tray icon state and tooltip handling.
- `src-tauri/src/sound_service.rs`: reminder sound playback.
- `src-tauri/src/db.rs`: SQLite persistence, migration, and summary queries.

Reminder and break windows are created on demand and closed after use, avoiding stale hidden WebView state.

## Release Build

```bash
npm run tauri:build
```

Windows build outputs:

```text
src-tauri/target/release/app.exe
src-tauri/target/release/bundle/nsis/GazeRest_1.0.1_x64-setup.exe
src-tauri/target/release/bundle/msi/GazeRest_1.0.1_x64_en-US.msi
```

For a quick release executable without installers:

```bash
npx tauri build --no-bundle
```

The `release/v1.0.0/` directory is a historical release copy. For distribution, use the latest package generated by `npm run tauri:build`.
